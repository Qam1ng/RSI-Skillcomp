# 短报告：第一个合成技能 pick_object 的验证结果

2026-10-19 · 白话版 · 详细账见 `journal/20261019_campaign.md` 与 `macros/pick_object.provenance.json`

**我们造的那个"拿东西"技能，机器人用它在 5 个没见过的新场景里试了 5 次，
5 次都把酒瓶抓起来举稳了。这个技能合格了。**

但整个任务（把瓶子放进碗里）5 次都没完成——因为"放进碗"那一段不是技能干的，
是临时手写的几行凑数代码，它每次都在同一个地方失手（往碗上方下放时动不了，
瓶子没放进去）。**锅在凑数代码，不在技能。**

过程中技能本身返工了两次：

1. 第一版有个代码错误（一跑就崩，几秒就被测试逮住）；
2. 第二版抓瓶子的位置算得不好（5 次只成 1 次）；
3. 把失败原因喂回去重写后，第三版 5 发 5 中。

## 三句话总结

1. **技能好使**：换 5 个没见过的摆法都能抓起来（几何量每次现场重算，不是背答案）；
2. **测试有用**：两个真问题都是它几秒钟逮出来的，喂回去就修好了；
3. **下一步明确**：把"放东西"也做成同样的技能，代替凑数代码——
   "拿"+"放"两个技能拼起来，整个任务就该通了。

全程花费大约一美分（3 次模型调用，共约 1.7 万 token）。
