# 2026-10-18 v0 骨架落地

## 做了什么

- 建仓 ~/skillcomp（Qstation），包 skillcomp，零第三方依赖（Python 3.12 标准库）。
- 五个核心件：轨迹协议(trace.py)、技能卡+库(skill.py)、合成器(compose.py，
  declared/observed 两种合成 + n-gram 挖掘 + 准入门)、运行时垫片(runtime.py，
  条件核对/重试/回退报告/事件标签)、适配器接口(adapters/base.py)。
- 玩具环境 drawer_world（抽屉-台面，声明式条件，可注入单步失败与结构意外）
  + BFS 占位规划器（真实场景中该角色由 harness 的 LLM 扮演）。
- 测试 9/9 过：合成代数(含不兼容拒绝、先用后删合法)、observed 合成、挖掘与准入、
  回退(结构意外→abort 带断点指针；状态意外→重试救回 dechunk_retry_ok)、
  端到端决策点下降且成功率不降。
- demo_curve：玩具任务 5 决策点 → 合成后 1 决策点，原子步不变，成功率不变。
  【玩具数字，不进报告】

## 设计决定（记理由）

- 条件两档 declared/observed：真实 harness 日志未必给谓词快照，observed 用
  快照交集近似，卡上标 origin，诚实分层。
- v0 宏接地不泛化：泛化（参数提升）是研究内容不是工程内容，放 v1。
- "变短"的度量对象 = 决策点（规划者的决定数/大模型调用的代理），不是物理动作数。
